How to read this

Treat every number on this page as in-sample.
  • Simulated on real 1-min price data, same signal/exit code the live engine uses — but no slippage, and P&L is index points × current lot size (NIFTY 75, SENSEX 20), not real option premiums.
  • The weekday rule (no new entries Tue/Thu) and the gap-guard (no entry whose prev-day High/Low condition a gap alone satisfied) were both added after looking at earlier data from this same period — treat them as forward-test candidates, not proven edges.
  • A third rule (pause all entries after a big gap until 10:30) was tested, found to remove net-positive trades, and removed on 2026-11-10 — see the project's own notes for that analysis.
  • That's why this project runs as paper trading, not real money: to test the rules on data the backtest never saw.
